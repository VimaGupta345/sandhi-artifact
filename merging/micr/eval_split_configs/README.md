# Generated eval-split configs (regenerated at run time)

This directory holds the per-task P/M split configs (`<task>_{P,M}.yaml`,
`*.spec.json`, `_micr_split_*.py` hooks) plus the full-set variants
(`ifeval_nothink.yaml`, `medqa_4options_fs.yaml`). They are **auto-generated by
`micr/eval_splits.py`** against the *installed* lm_eval (the generator resolves
each parent task YAML from the live environment), so they are intentionally not
checked in: configs generated in one environment embed absolute paths that
break in another, and lm_eval's TaskManager aborts on the first stale YAML in
this directory even for tasks the current run never touches.

They materialize automatically: the driver's `prereq` stage
(`scripts/run_figures.py`, part of `--stages all`) runs
`python micr/eval_splits.py --task <t> --seed 42` for every task in the
selected sets. To generate one manually:

    python micr/eval_splits.py --task mmlu_econometrics --splits P,M

Override the output directory with `$MICR_EVAL_SPLIT_CONFIG_DIR`.
